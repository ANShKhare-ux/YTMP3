--- B. Backend Engine & Security (server/) ---

[M5] [CRITICAL SECURITY] Fix SSRF & Unbounded Memory Buffer in `/api/photo-download`
  - Where: server/index.js (lines 393-425)
  - Current Behavior: `/api/photo-download` only checks `url.startsWith('https://')`
    (does NOT call `normalizeUrl(url)` to block internal/private/metadata IPs or
    follow-redirect SSRF) and loads the entire response into memory via
    `await upstreamRes.arrayBuffer()` without a max-bytes limit.
  - Improvement: Validate URL via `normalizeUrl(url)`, block redirects to private
    IPs, verify `content-type` is `image/*`, enforce a strict size limit (e.g.
    25 MB), and stream response chunks cleanly to `res`.

[M6] [SECURITY / RULE] Eliminate Shell String Invocation in `cancelConversion`
  - Where: server/converter.js (line 1829)
  - Current Behavior: Calls `execSync(\`taskkill /pid ${pid} /T /F\`)` via shell
    interpolation instead of argument array (violates `AGENTS.md` Rule 2.5).
  - Improvement: Use `execFileSync('taskkill', ['/pid', String(Number(pid)), '/T', '/F'], { stdio: 'ignore' })`
    with integer PID validation.

[M7] [HIGH IMPACT] Convert HTTP 429 Hard Rejection into Persistent Conversion Queue
  - Where: server/index.js (lines 129-136) & server/converter.js
  - Current Behavior: When 3 jobs are active (`MAX_CONCURRENT_CONVERSIONS = 3`),
    the 4th request fails immediately with HTTP `429 Too Many Requests`.
  - Improvement: Add a FIFO **Job Queue** (`status: 'queued'`) so users can submit
    multiple links or entire playlists and watch them process automatically as
    worker slots free up.

[M8] [HIGH IMPACT] Playlist & Multi-Track Batch Extraction Mode

  - Current Behavior: `yt-dlp` enforces `--no-playlist` everywhere; pasting a

  - Improvement: Detect playlist URLs, fetch entries via `--flat-playlist --dump-single-json`,
    display a selectable track checklist in the UI, and batch-queue selected tracks
    (with optional ZIP packaging).

[M9] [HIGH IMPACT] Permanent Library Output Mode (Stop 2-Hour Eviction of Saved Tracks)

  - Where:
      * android-app/app/src/main/kotlin/com/sonicwave/app/ui/SonicWaveAppScreen.kt (lines 111-147, 852)
      * android-app/app/src/main/kotlin/com/sonicwave/app/engine/ConversionEngine.kt

  - Current Behavior: `AndroidManifest.xml` declares `FOREGROUND_SERVICE_DATA_SYNC`
